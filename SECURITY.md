# Security policy

## Supported versions

Only the latest version published to npm (built from `main`) receives fixes.

## Reporting a vulnerability

Please report vulnerabilities **privately** with GitHub's
[Report a vulnerability](https://github.com/Arffornia/Nexus_Java/security/advisories/new) button
(Security tab of this repository). Do not open a public issue.

Include the affected version, a description of the impact, and how to reproduce it.
You should get an answer within a few days.
